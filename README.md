# scoop-bucket

A [Scoop](https://scoop.sh) bucket for
[Calepin](https://github.com/vincentarelbundock/calepin), a Rust CLI that turns
`.typ` files into computational notebooks.

```powershell
scoop bucket add vincentarelbundock https://github.com/vincentarelbundock/scoop-bucket
scoop install calepin
```

Upgrade with:

```powershell
scoop update calepin
```

Calepin also needs the [Typst](https://github.com/typst/typst) CLI (0.15.0 or
newer) on your `PATH`:

```powershell
scoop install typst
```

Scoop owns the copy it installs, so the `calepin-update` helper is not part of
it and `calepin update` does not apply; upgrade with Scoop instead.

`bucket/calepin.json` is generated by Calepin's release workflow
(`scripts/update-scoop-bucket.sh` in the main repo). Do not edit it by hand.
